# 深度学习模型训练

## 1. 标准训练流程

1. 数据准备 -> 划分训练集/验证集/测试集
2. 模型初始化 -> 权重初始化
3. 前向传播 -> 计算预测输出
4. 计算损失 -> 衡量预测与真实差距
5. 反向传播 -> 计算梯度
6. 参数更新 -> 优化器调整权重
7. 重复3-6步 -> 多轮迭代（epoch）
8. 验证评估 -> 监控模型性能

## 2. 批量训练策略

| 策略 | 说明 | 优缺点 |
|:---|:---|:---|
| 批量梯度下降 (BGD) | 每次用全部数据更新 | 稳定但慢，内存需求大 |
| 随机梯度下降 (SGD) | 每次用单个样本更新 | 快但波动大 |
| 小批量梯度下降 (Mini-batch) | 每次用一批样本（常用32-256） | 平衡速度与稳定性 |

## 3. 学习率调度

### 3.1 常用策略

- **Step Decay**：每隔固定epoch降低学习率
- **Exponential Decay**：指数衰减
- **Cosine Annealing**：余弦退火
- **ReduceLROnPlateau**：验证集损失不下降时降低学习率
- **Warmup**：训练初期逐渐增大学习率

### 3.2 学习率影响

- 过大：损失震荡，可能发散
- 过小：收敛极慢，可能陷入局部最优
- 适中：平稳收敛到较优解

## 4. 早停 (Early Stopping)

- 监控验证集损失
- 当验证损失连续多轮不下降时停止训练
- 保存验证损失最小时的模型参数
- 有效防止过拟合

## 5. 梯度问题

### 5.1 梯度消失 (Vanishing Gradient)

**原因**：
- 激活函数导数小于1（如sigmoid在两端饱和）
- 深层网络链式法则连乘导致梯度指数级衰减

**解决方法**：
- 使用ReLU等激活函数
- 权重初始化优化（Xavier、He初始化）
- 批归一化 (Batch Normalization)
- 残差连接 (Residual Connection)

### 5.2 梯度爆炸 (Exploding Gradient)

**原因**：
- 权重过大导致梯度连乘后指数级增长

**解决方法**：
- 梯度裁剪 (Gradient Clipping)
- 权重正则化
- 更小的学习率

## 6. 检查点保存

- 定期保存模型参数
- 保存最优模型（基于验证集指标）
- 支持训练中断后恢复

## 7. 训练监控指标

- 训练损失 / 验证损失
- 训练准确率 / 验证准确率
- 学习率变化
- 梯度范数
