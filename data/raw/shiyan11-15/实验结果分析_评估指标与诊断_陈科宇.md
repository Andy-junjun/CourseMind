# 实验结果分析与模型诊断

## 1. 分类任务评估指标

### 1.1 混淆矩阵 (Confusion Matrix)

                预测为正    预测为负
实际为正        TP          FN
实际为负        FP          TN

- **TP (True Positive)**：真正例，预测为正且实际为正
- **FP (False Positive)**：假正例，预测为正但实际为负
- **TN (True Negative)**：真反例，预测为负且实际为负
- **FN (False Negative)**：假反例，预测为负但实际为正

### 1.2 基本指标

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| 准确率 (Accuracy) | (TP+TN)/(TP+FP+TN+FN) | 总体正确率 |
| 精确率 (Precision) | TP/(TP+FP) | 预测为正的样本中实际为正的比例 |
| 召回率 (Recall) | TP/(TP+FN) | 实际为正的样本中被正确预测的比例 |
| F1分数 | 2*Precision*Recall/(Precision+Recall) | 精确率和召回率的调和平均 |

### 1.3 准确率 vs F1分数

- **类别平衡**时：准确率即可
- **类别不平衡**时：优先看F1分数或精确率/召回率

## 2. 回归任务评估指标

| 指标 | 特点 |
|:---|:---|
| MSE | 对异常值敏感 |
| RMSE | 与目标变量同量纲 |
| MAE | 对异常值更鲁棒 |
| R2 | 解释方差比例 |

## 3. 学习曲线分析

### 3.1 损失曲线

损失

  |   /
  |  /     ____ 验证损失
  | /     /
  |/_____/
  +--------------> epoch

### 3.2 过拟合判断

| 现象 | 诊断 | 解决方案 |
|:---|:---|:---|
| 训练损失下降，验证损失上升 | 过拟合 | 增加数据、正则化、Dropout、早停 |
| 训练损失上升，验证损失上升 | 欠拟合/训练发散 | 降低学习率、简化模型、检查数据 |
| 训练损失高，验证损失也高 | 欠拟合 | 增加模型容量、训练更久、减少正则化 |
| 训练损失低，验证损失也低且接近 | 拟合良好 | 保持当前配置 |

## 4. 模型对比与选择

### 4.1 对比维度

- 准确率/F1等核心指标
- 推理速度
- 模型大小
- 训练时间
- 可解释性

### 4.2 交叉验证

- K折交叉验证：将数据分为K份，轮流作为验证集
- 减少数据划分随机性对评估结果的影响
- 更可靠的性能估计

## 5. 错误分析

- 分析模型预测错误的样本
- 找出错误模式（如某类特别容易混淆）
- 针对性改进数据或模型

## 6. 可视化工具

- **TensorBoard**：训练过程可视化
- **matplotlib/seaborn**：自定义图表
- **混淆矩阵热力图**：直观展示分类错误分布
- **ROC曲线**：评估不同阈值下的分类性能
