# GAN (Generative Adversarial Networks)

## 1. 基本思想

GAN 由两个网络通过对抗训练共同学习：

- **生成器 G**：从随机噪声生成假样本，试图欺骗判别器
- **判别器 D**：区分真实样本和生成样本

二者形成零和博弈，最终达到纳什均衡。

## 2. 网络结构

随机噪声 z ~ p(z) -> [生成器 G] -> 假样本 G(z)
真实样本 x ~ p_data(x) -> [判别器 D] -> 真假概率
假样本 G(z) -> [判别器 D] -> 真假概率

## 3. 目标函数

### 3.1 判别器目标

最大化正确分类真实样本和假样本的能力。

### 3.2 生成器目标

最小化被判别器识破的概率。

### 3.3 整体目标（极小极大博弈）

min_G max_D V(D, G) = E[log D(x)] + E[log(1 - D(G(z)))]

## 4. 训练过程

1. 固定 G，更新 D（提升判别能力）
2. 固定 D，更新 G（提升生成质量）
3. 交替迭代直至收敛

## 5. 训练难点

### 5.1 模式坍塌 (Mode Collapse)

- 生成器只学会生成少数几类样本
- 多样性不足

### 5.2 训练不稳定

- G 和 D 训练速度不平衡
- 损失函数不收敛
- 梯度消失问题

## 6. 常见改进变体

| 变体 | 改进点 |
|:---|:---|
| DCGAN | 使用卷积层，提出稳定训练架构 |
| WGAN | 使用Wasserstein距离替代JS散度，训练更稳定 |
| WGAN-GP | 梯度惩罚替代权重裁剪 |
| CGAN | 条件GAN，控制生成类别 |
| ACGAN | 辅助分类GAN，同时优化分类任务 |
| StyleGAN | 风格映射网络，精细控制生成风格 |

## 7. 应用场景

- 图像生成（人脸、风景、艺术作品）
- 图像超分辨率
- 图像风格迁移
- 数据增强
- 文本到图像生成
