## 1. CNN 为什么适合图像

图像具有空间局部结构，相邻像素之间高度相关。全连接网络把每个像素都看成独立输入，会产生大量参数，也忽略局部邻域结构。卷积神经网络通过局部连接和权值共享，更适合提取图像中的边缘、纹理、形状和语义模式。

CNN 的两个关键归纳偏置：

```text
局部连接：卷积核只关注局部感受野
权值共享：同一个卷积核在不同位置复用
```

这使模型参数更少，也让特征检测具有平移等变性。

## 2. 卷积核与特征图

卷积核是一组可学习权重。它在输入图像或上一层特征图上滑动，对局部区域做加权求和，得到新的特征图。不同卷积核会学习不同模式，例如边缘方向、颜色变化、局部纹理或更高层语义部件。

常见超参数包括：

```text
kernel size 卷积核大小
stride 步幅
padding 填充
channel 通道数
dilation 空洞率
```

步幅越大，输出空间尺寸越小；padding 可以控制边界信息是否保留；通道数决定输出特征图数量。

## 3. 池化与下采样

池化层通过局部区域聚合降低空间分辨率。最大池化保留最强响应，平均池化保留平均趋势。池化可以减少计算量、扩大感受野，并增强一定程度的位置鲁棒性。

现代 CNN 也常用步幅卷积替代池化。无论采用哪种方式，下采样的目标都是逐渐压缩空间信息，并把浅层局部特征组合成高层语义特征。

## 4. 经典 CNN 结构

早期 CNN 结构通常由卷积、激活、池化和全连接层组成。随着网络加深，残差连接成为重要技术。ResNet 通过学习残差函数，让梯度更容易传播，缓解深层网络退化问题。

典型层次可以理解为：

```text
低层：边缘、颜色、角点
中层：纹理、局部形状
高层：物体部件、类别相关语义
```

这种层次化表示是深度学习在视觉任务中成功的重要原因。

## 5. CNN 的局限

CNN 擅长局部空间模式，但对长距离依赖和全局关系建模不如注意力机制直接。对于图像分类，CNN 仍然高效；对于需要全局上下文的任务，Vision Transformer 等模型通过自注意力捕获更广范围的关系。

CNN 还可能对旋转、尺度变化、遮挡和分布偏移敏感，需要数据增强、归一化和更丰富训练数据提高鲁棒性。
