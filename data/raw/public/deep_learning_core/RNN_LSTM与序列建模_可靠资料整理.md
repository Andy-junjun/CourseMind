## 1. 序列建模问题

序列数据的特点是样本之间存在顺序依赖。文本、语音、时间序列、用户行为和视频帧都属于序列数据。普通前馈网络假设输入维度固定且相互独立，不适合直接表达时间依赖。

循环神经网络通过隐藏状态保存历史信息：

```text
h_t = f(W_x x_t + W_h h_{t-1} + b)
y_t = g(h_t)
```

其中 `h_t` 是当前隐藏状态，包含当前输入和过去状态的信息。

## 2. RNN 的优势与问题

RNN 可以处理可变长度序列，并在不同时间步共享参数。参数共享使模型能够学习跨时间的模式，例如语言中的上下文关系。

但普通 RNN 容易遇到梯度消失和梯度爆炸。反向传播需要沿时间展开，时间步越长，梯度越容易在反复相乘中衰减或放大。因此普通 RNN 难以学习长距离依赖。

## 3. LSTM 的门控机制

LSTM 引入记忆单元和门控结构。它通过输入门、遗忘门和输出门控制信息的写入、保留和输出。

核心直觉：

```text
遗忘门：决定旧记忆保留多少
输入门：决定新信息写入多少
候选记忆：生成可写入的新内容
输出门：决定当前隐藏状态输出多少
```

LSTM 的记忆单元提供更稳定的信息通道，使梯度更容易跨较长时间传播，从而缓解长期依赖问题。

## 4. GRU

GRU 是另一种门控循环网络，结构比 LSTM 简洁。它通常包含更新门和重置门，把隐藏状态和记忆状态合并。GRU 参数更少，训练速度可能更快，在数据量较小或任务较简单时常作为 LSTM 的替代。

## 5. RNN 与 Transformer 的区别

RNN 按时间顺序递归处理序列，天然适合流式输入，但并行能力较弱。Transformer 使用自注意力直接建模任意位置之间的关系，训练时更容易并行，也更擅长长距离依赖。

对比可以概括为：

```text
RNN：顺序递归，隐藏状态传递历史
LSTM/GRU：用门控缓解长期依赖
Transformer：用自注意力直接连接序列位置
```
