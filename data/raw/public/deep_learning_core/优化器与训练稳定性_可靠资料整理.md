# 优化器与训练稳定性

## 1. 梯度下降

梯度下降的基本思想是沿着损失函数下降最快的方向更新参数。设参数为 `theta`，学习率为 `eta`，损失函数为 `L`，更新形式为：

```text
theta <- theta - eta * grad_theta L
```

全量梯度下降使用全部训练样本计算梯度，稳定但慢；随机梯度下降每次只用一个或一小批样本，速度快但噪声大。实际训练通常使用 mini-batch SGD，在效率和稳定性之间折中。

## 2. 学习率为什么重要

学习率控制每次参数更新的步长。学习率过大，损失可能震荡甚至发散；学习率过小，收敛会很慢，也可能停在较差区域。训练深度网络时，学习率往往比模型细节更影响最终效果。

常见学习率策略包括：

```text
固定学习率
阶梯衰减
指数衰减
余弦退火
warmup
ReduceLROnPlateau
```

Transformer 等大模型常使用 warmup，让训练前期逐渐增大学习率，减少初始阶段梯度不稳定。

## 3. 动量方法

SGD 的更新方向容易受 mini-batch 噪声影响。动量方法会维护历史梯度的指数滑动平均，让更新方向更平滑。直观上，动量像给参数更新加入“惯性”：如果多个 batch 都指向相似方向，更新会加速；如果梯度方向来回震荡，动量会抵消部分震荡。

动量适合损失曲面存在狭长峡谷的场景，可以减少横向摆动，提高纵向前进速度。

## 4. Adam 优化器

Adam 同时估计梯度的一阶矩和二阶矩。一阶矩类似动量，表示梯度方向的移动平均；二阶矩表示梯度平方的移动平均，用于自适应调整每个参数的学习率。

Adam 的优点：

```text
对学习率不如 SGD 敏感
适合稀疏梯度
训练初期收敛快
在 NLP 和 Transformer 训练中常用
```

Adam 的限制：

```text
不一定总比 SGD 泛化好
权重衰减需要谨慎处理
过大的学习率仍会导致不稳定
```

AdamW 把权重衰减从梯度更新中解耦，在训练 Transformer 类模型时更常见。

## 5. 训练稳定性问题

训练深度网络时，常见不稳定现象包括：

```text
loss 变成 NaN
梯度爆炸
训练集 loss 下降但验证集变差
学习率过大导致震荡
batch 太小导致梯度噪声过大
初始化不合理导致信号衰减
```

排查顺序可以是：

```text
检查数据和标签
降低学习率
检查损失函数与输出层是否匹配
观察梯度范数
开启梯度裁剪
尝试标准化输入
减少模型复杂度或增加正则化
```

## 6. 对 CourseMind 的意义

CourseMind 如果进行 embedding 微调，优化器选择会直接影响检索质量。微调时不应只看训练 loss，还要看检索评测指标，例如 Recall@5、MRR、正样本相似度是否高于负样本。对于小数据集，AdamW、较小学习率、早停和验证集评估通常比盲目增加 epoch 更可靠。
