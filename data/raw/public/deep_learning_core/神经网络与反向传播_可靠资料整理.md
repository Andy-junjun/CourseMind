## 1. 神经网络的基本计算

神经网络可以看成由多层可学习函数组成的复合函数。输入向量先经过线性变换，再经过非线性激活函数。单个神经元常写成：

```text
z = w^T x + b
a = f(z)
```

其中 `x` 是输入，`w` 是权重，`b` 是偏置，`f` 是激活函数，`a` 是输出。多层网络把前一层的输出作为后一层输入，从而形成逐层抽象。浅层通常学习局部或简单模式，深层可以组合出更复杂的表示。

如果没有非线性激活函数，多层线性变换仍然等价于一个线性变换，网络表达能力会非常有限。因此 ReLU、Sigmoid、Tanh、GELU 等激活函数的核心作用是引入非线性，使网络能够拟合复杂函数。

## 2. 损失函数与学习目标

训练神经网络的目标不是直接“记住答案”，而是最小化损失函数。损失函数衡量模型预测与真实标签之间的差异。回归任务常用均方误差，分类任务常用交叉熵。训练过程通过大量样本估计总体风险，让模型在未见数据上也能保持较低误差。

一次训练迭代通常包含：

```text
输入样本 -> 前向传播 -> 计算损失 -> 反向传播 -> 更新参数
```

前向传播负责得到预测值，反向传播负责计算每个参数对损失的影响，优化器负责根据梯度调整参数。

## 3. 反向传播的核心思想

反向传播本质上是链式法则在计算图上的高效应用。神经网络由很多简单运算组成，损失函数位于计算图末端。为了知道某个早期参数应该如何调整，需要计算损失对该参数的偏导数。

如果一个变量通过多层函数影响最终损失，链式法则会把局部导数逐层相乘：

```text
dL/dw = dL/da * da/dz * dz/dw
```

反向传播从输出层开始，把误差信号逐层传回隐藏层。每一层只需要保存前向传播中的局部中间量，就能计算本层参数梯度。这使得深层网络可以在可接受的时间内训练。

## 4. 自动微分与计算图

现代深度学习框架通常不要求手写每个梯度公式。PyTorch、TensorFlow 等框架会记录张量运算形成计算图，然后自动执行反向模式自动微分。对于神经网络这种“输入多、输出通常是一个标量损失”的场景，反向模式自动微分非常高效。

需要注意的是，自动微分不是数值差分。数值差分通过扰动参数估计梯度，计算成本高且不稳定；自动微分基于精确的链式法则，在浮点精度范围内更可靠。

## 5. 梯度消失与梯度爆炸

深层网络反向传播时会多次相乘局部导数。如果导数长期小于 1，梯度可能逐层衰减，形成梯度消失；如果导数长期大于 1，梯度可能快速放大，形成梯度爆炸。RNN 中这个问题尤其明显，因为同一变换会沿时间步反复传播。

常见缓解方法包括：

```text
使用 ReLU 系激活函数
合理初始化权重
Batch Normalization 或 Layer Normalization
残差连接
梯度裁剪
LSTM/GRU 等门控结构
```

## 6. 对 CourseMind 的意义

在 CourseMind 中，神经网络与反向传播是解释 embedding 模型和 MiniRanker 的基础。Embedding 模型通过反向传播学习“问题”和“文本片段”的语义接近关系；MiniRanker 可以用检索特征学习更好的排序函数。系统演示时可以强调：检索不是简单关键词匹配，而是把文本映射到可学习的向量空间，再用训练目标优化表示。
