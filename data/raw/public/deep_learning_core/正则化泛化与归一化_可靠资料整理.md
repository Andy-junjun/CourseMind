# 正则化、泛化与归一化

## 1. 过拟合与泛化

过拟合指模型在训练集上表现很好，但在验证集或测试集上表现明显变差。深度网络参数量大，表达能力强，如果数据规模不足或噪声较多，就可能记住训练样本中的偶然模式。

判断过拟合通常看：

```text
训练损失持续下降
验证损失先下降后上升
训练准确率高而验证准确率低
训练集与验证集指标差距持续扩大
```

欠拟合则相反，训练集和验证集表现都不好，说明模型能力不足、特征不足或训练不充分。

## 2. L1 与 L2 正则化

L1 正则化在损失中加入权重绝对值之和，倾向于让部分权重变成 0，因此常和稀疏特征选择联系在一起。L2 正则化在损失中加入权重平方和，倾向于让权重整体变小，因此常被称为权重衰减。

正则化的核心不是让训练误差最低，而是限制模型复杂度，让模型学习更稳定、更可泛化的规律。

## 3. Dropout

Dropout 在训练时随机丢弃一部分神经元输出，使网络不能过度依赖某几个特征。它可以看作一种隐式集成：每次训练都相当于采样一个子网络，最终模型综合了许多子网络的效果。

Dropout 的作用：

```text
减少神经元共适应
提升特征鲁棒性
降低过拟合风险
在全连接层和部分深层模型中常用
```

推理时通常不再随机丢弃，而是使用完整网络，并对激活或权重进行等价缩放。

## 4. Batch Normalization

Batch Normalization 对 mini-batch 中的中间激活进行标准化，再通过可学习参数恢复表示能力。它可以缓解训练过程中激活分布变化带来的不稳定，使较大学习率更容易使用，也有一定正则化效果。

BatchNorm 常见于 CNN；Transformer 中更常用 LayerNorm，因为序列建模和小 batch 场景下，按样本内部特征归一化更方便。

## 5. Early Stopping 与数据增强

Early Stopping 通过监控验证集指标决定何时停止训练。当验证损失不再改善时继续训练，模型可能开始记住噪声。早停等价于限制训练过程复杂度，是一种简单有效的正则化。

数据增强通过变换训练样本增加有效数据量。图像任务中常见随机裁剪、翻转、颜色扰动；文本任务中可以使用同义改写、回译、随机遮蔽等方法。数据增强必须保持标签语义不变，否则会引入错误监督。

## 6. 对 CourseMind 的意义

CourseMind 的数据量目前较小，训练 embedding 或 MiniRanker 时很容易过拟合。更稳妥的做法是：

```text
先使用预训练中文 embedding
用少量高质量问答对进行轻微微调
保留验证问题集
用 Recall@5 和 MRR 评估
设置早停
不要盲目扩大训练轮数
```

系统汇报时可以把正则化作为“为什么小数据微调要谨慎”的理论依据。
