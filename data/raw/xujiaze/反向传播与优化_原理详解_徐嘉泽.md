## 一、损失函数：衡量预测与现实的差距

### 1.1 为什么需要损失函数

训练神经网络本质上是在解一个优化问题：找一组参数，使得网络输出尽可能接近真实值。为了"尽可能接近"这个模糊的目标变得可操作，我们需要一个**损失函数**来量化"不接近的程度"。损失函数把预测值和真实值之间的差距转化为一个数值，数值越小说明预测越准。

### 1.2 回归任务：均方误差与平均绝对误差

对于预测连续值的任务（如房价预测、温度预测），最常用的损失函数是**均方误差（MSE）**：

```
MSE = (1/n) Σ(yᵢ - ŷᵢ)²
```

它计算每个样本的预测误差，平方后取平均。平方的好处是处处可导，方便用梯度下降优化；坏处是异常值会被放大（因为平方会加剧大误差的影响）。

如果数据中存在较多异常值，可以使用**平均绝对误差（MAE）**：

```
MAE = (1/n) Σ|yᵢ - ŷᵢ|
```

MAE对异常值更鲁棒，但在误差为0的点不可导，实际中通常使用子梯度来处理。

### 1.3 分类任务：交叉熵损失

对于分类任务，我们需要一个能衡量概率分布差异的损失函数。这里涉及信息论中的几个概念。

**熵**描述了一个随机事件的不确定性。如果一件事有多种可能结果，且每种结果概率相等，那这件事的不确定性就很大，熵就高。如果几乎只有一件事会发生，不确定性就小，熵就低。

**交叉熵**描述的是：用一个概率分布去编码另一个分布时，需要多少信息量。如果两个分布很接近，编码效率就高，交叉熵就小；如果两个分布差异很大，编码效率就低，交叉熵就大。

在神经网络中，我们希望网络输出的概率分布（通过Softmax或Sigmoid产生）与真实标签分布尽可能接近。因此，最小化交叉熵损失就是在迫使模型输出更准确的概率。

**为什么分类不用MSE？** 这里有两个关键原因。首先，交叉熵在预测严重错误时会产生更大的梯度（因为log函数在接近0时趋向负无穷），这能让模型更快纠正错误。其次，当配合Sigmoid或Softmax使用时，交叉熵的梯度公式可以抵消激活函数在饱和区的导数衰减，避免了梯度消失。而MSE在分类任务中会导致梯度很小，收敛极其缓慢。

### 1.4 KL散度与交叉熵的关系

KL散度（Kullback-Leibler Divergence）衡量的是：用一个分布近似另一个分布时，损失了多少信息。它的公式是：

```
KL(p||q) = 交叉熵(p,q) - 熵(p)
```

由于真实分布的熵是固定的，所以**最小化交叉熵等价于最小化KL散度**。这意味着在优化过程中，交叉熵和KL散度本质上是同一回事，只是从不同角度描述概率分布的差异。

## 二、梯度下降：沿着最陡的方向下山

### 2.1 核心思想

想象你站在一个山坡上，目标是走到山谷最低点。你看不见整个地形，但你能感知脚下哪个方向最陡。梯度下降就是每次都朝着**下降最快**的方向（即梯度的反方向）迈一步。

参数更新公式：

```
参数 = 参数 - 学习率 × 梯度
```

这里的学习率控制每一步迈多大。太大了容易跨过谷底或在山谷间震荡；太小了要走很久才能到达。学习率是最关键的超参数之一。

### 2.2 三种梯度下降策略

**批量梯度下降**：每次计算都使用全部训练数据。优点是梯度估计准确，收敛稳定；缺点是需要计算整个数据集，速度慢，内存消耗大。

**随机梯度下降**：每次只用一个样本。优点是速度快，每次迭代开销小；缺点是梯度噪声大，更新方向不稳定。但有趣的是，这种噪声有时候反而是好事——它可能帮助跳出局部最优解。

**小批量梯度下降**：折中方案，每次用一小批样本（如32、64、128个）。既保证了梯度估计的基本稳定性，又避免了全量计算的开销。这是目前深度学习中最常用的策略，几乎成为标准做法。

### 2.3 学习率调度的智慧

固定学习率往往不是最优的。通常的策略是：初期用较大学习率快速下降，接近目标时减小学习率精细调优。常见的调度方法包括：

- **阶梯式衰减**：每隔固定轮数（如10个epoch）将学习率乘以一个小于1的因子
- **指数衰减**：学习率按指数曲线逐渐下降
- **余弦退火**：学习率按余弦曲线周期性变化，有助于跳出局部最优
- **预热（Warm-up）**：初期先用很小学习率，然后逐渐增大，防止训练早期的梯度爆炸

## 三、反向传播：高效计算梯度

### 3.1 问题的困难性

神经网络通常有成千上万甚至上亿个参数。要计算损失函数对每个参数的梯度，如果逐个参数单独计算，计算量将是天文数字。反向传播算法的伟大之处，在于它利用网络结构的特点，把计算复杂度降低到与一次前向传播相当。

### 3.2 链式法则：反向传播的数学基础

反向传播的本质是**链式法则**。假设一个函数可以分解为多层嵌套：z = f(y), y = g(x)。那么z对x的导数等于 z对y的导数乘以 y对x的导数。

在神经网络中，损失函数关于输入层某个参数的梯度，需要从输出层开始，逐层向后传递，每一层都乘上该层的局部导数。这就像一个链条，从最后一环开始，一环一环传到第一环。

### 3.3 计算图：直观理解反向传播

计算图是把复杂运算拆解成简单步骤的图形化表示。每个节点只做一件简单的事（如加法、乘法、激活函数），节点之间有数据流动。

反向传播在计算图上的规则很清晰：
1. 从输出节点（损失）开始，每个节点都收到一个"上游梯度"
2. 节点计算自己的局部梯度，用链式法则把上游梯度乘以局部梯度
3. 把结果传递给所有输入节点
4. 如果有多条路径到达某个参数，把各条路径的梯度相加

### 3.4 自动微分：让框架帮我们计算

现代深度学习框架（如PyTorch、TensorFlow）的核心能力之一是**自动微分（Automatic Differentiation）**。用户只需要定义前向计算过程，框架会自动构建计算图并执行反向传播。

自动微分有两种模式：
- **前向模式**：从输入开始，随着计算进行同步计算导数。适合输入少、输出多的场景
- **反向模式**：从输出开始，反向传播导数。这是神经网络的标配，因为通常我们只有一个标量损失输出，但需要计算大量参数的梯度

反向模式的计算量与网络复杂度成正比，而不是与参数数量成正比，因此效率极高。

### 3.5 静态图与动态图

**静态图**在程序运行前就构建好计算图（如TensorFlow 1.x），好处是可以进行全局优化，执行效率高；缺点是不够灵活，调试困难。

**动态图**在运行时即时构建（如PyTorch），好处是灵活直观，可以像写普通Python程序一样写网络，调试方便；缺点是难以做全局优化。目前动态图已成为主流，TensorFlow 2.x也支持了动态图模式。

## 四、反向传播与梯度下降的关系

很多人容易混淆这两个概念，它们其实是**分工合作**的关系：

- **反向传播**负责计算梯度：回答"每个参数对损失有多大影响"
- **梯度下降**负责更新参数：回答"知道了影响后，参数应该往哪调、调多少"

完整的训练流程可以概括为：

```
前向传播 → 计算损失 → 反向传播求梯度 → 梯度下降更新参数 → 重复
```

## 五、深层网络的训练难点

### 5.1 梯度消失与梯度爆炸

在深层网络中，梯度需要经过很多层反向传播。由于链式法则中的梯度是连乘的，如果每层的梯度都小于1，多层相乘后就会指数级衰减，导致前面的层几乎接收不到梯度信号——这就是**梯度消失**。

相反，如果梯度大于1，多层相乘后会指数级增长，导致参数更新剧烈震荡——这就是**梯度爆炸**。

**缓解方法**：使用ReLU等导数不饱和的激活函数、合理的权重初始化（如Xavier/He初始化）、批归一化（Batch Normalization）、梯度裁剪、残差连接等。

### 5.2 非凸优化问题

神经网络的损失函数不是凸函数（不像线性回归有唯一的全局最优解）。它有很多局部最优解和鞍点，优化过程可能在某个次优解附近徘徊。不过在实践中，局部最优解通常也足够好，真正的麻烦更多是鞍点导致的训练停滞。

## 六、总结

| 组件 | 核心作用 | 关键概念 |
|------|---------|---------|
| 损失函数 | 量化预测误差 | 交叉熵（分类）、MSE（回归）、KL散度 |
| 梯度下降 | 优化参数 | 学习率、BGD/SGD/Mini-Batch、学习率调度 |
| 反向传播 | 高效计算梯度 | 链式法则、计算图、自动微分、误差项 |
| 训练难点 | 深层网络挑战 | 梯度消失、梯度爆炸、非凸优化 |

理解损失函数、梯度下降和反向传播这三者如何配合，是掌握神经网络训练的基石。前向传播计算预测，损失函数衡量误差，反向传播追溯责任，梯度下降执行修正——这个循环构成了现代深度学习的核心训练流程。
