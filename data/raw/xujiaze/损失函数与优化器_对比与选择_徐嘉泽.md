# 损失函数与优化器对比与选择

> 涵盖：损失函数、优化器
> 来源：个人整理，参考课程讲义与公开教材
> 作者：徐嘉泽

## 一、损失函数（Loss Function）

损失函数（Loss Function）是衡量神经网络预测值与真实值之间差距的数学函数。它为模型提供优化目标，指导参数更新的方向。选择合适的损失函数对模型性能至关重要。

### 1.1 为什么需要损失函数

在神经网络的训练过程中，我们需要一个**量化的标准**来判断模型预测的好坏。损失函数将这个标准转化为一个数值——损失值越小，说明模型预测越接近真实值。通过最小化损失函数，模型就能自动调整参数，逐步学习数据中的规律。

### 1.2 均方误差（Mean Squared Error，MSE）

**定义**：
```
MSE = (1/n) Σᵢ (yᵢ - ŷᵢ)²
```

其中 `yᵢ` 是真实值，`ŷᵢ` 是模型预测值，`n` 是样本数量。

**特点**：
- 计算预测值与真实值之间差值的平方和的平均值
- 对较大的误差给予更高的惩罚（因为平方会放大差异）
- 函数处处可导，适合梯度下降优化
- 输出是连续值（适用于回归任务）

**适用场景**：
- 回归任务（预测连续值，如房价、温度、股价等）
- 当异常值较少时，MSE 能很好地衡量预测质量

**缺点**：
- 对异常值（Outliers）敏感，因为平方会放大极端误差的影响
- 在分类任务中表现较差，因为分类输出是离散标签，不适合用平方误差

### 1.3 平均绝对误差（Mean Absolute Error，MAE）

**定义**：
```
MAE = (1/n) Σᵢ |yᵢ - ŷᵢ|
```

**特点**：
- 计算预测值与真实值之间绝对差的平均值
- 对异常值的敏感度低于 MSE（因为不取平方）
- 在某些点不可导（在 yᵢ = ŷᵢ 处），但在实际训练中使用子梯度即可

**适用场景**：
- 回归任务，特别是数据中存在较多异常值时
- 当希望损失函数对极端误差不那么敏感时

### 1.4 交叉熵损失（Cross-Entropy Loss）

交叉熵损失是分类任务中最常用的损失函数，它衡量模型输出的概率分布与真实标签分布之间的差异。

**二分类交叉熵（Binary Cross-Entropy）**：
```
BCE = - (1/n) Σᵢ [yᵢ log(ŷᵢ) + (1-yᵢ) log(1-ŷᵢ)]
```

其中 `yᵢ` ∈ {0, 1} 是真实标签，`ŷᵢ` ∈ (0, 1) 是模型预测的概率（通常通过 Sigmoid 输出）。

**多分类交叉熵（Categorical Cross-Entropy）**：
```
CE = - (1/n) Σᵢ Σⱼ yᵢⱼ log(ŷᵢⱼ)
```

其中 `yᵢⱼ` 是第 i 个样本第 j 类的真实标签（通常为 one-hot 编码），`ŷᵢⱼ` 是模型预测的概率（通过 Softmax 输出）。

**特点**：
- 对错误预测给予更强烈的惩罚（因为 log 函数在接近 0 时趋向负无穷）
- 在分类任务中收敛速度通常优于 MSE
- 与 Softmax 和 Sigmoid 配合良好，梯度计算简洁高效

**适用场景**：
- 二分类任务（输出层用 Sigmoid + BCE）
- 多分类任务（输出层用 Softmax + CCE）

### 1.5 分类任务为什么用交叉熵而不是 MSE

这是深度学习中的一个关键设计选择。原因包括：

1. **梯度大小**：当预测概率严重错误时（如真实标签为 1 但预测为 0.01），交叉熵会产生非常大的梯度，加速参数更新；而 MSE 的梯度较小，收敛缓慢

2. **梯度消失**：当使用 Sigmoid 激活函数时，MSE 在预测接近 0 或 1 时梯度会变得极小，导致参数几乎不更新；而交叉熵与 Sigmoid 的组合可以避免这个问题（因为交叉熵的梯度公式恰好抵消了 Sigmoid 的导数衰减）

3. **概率解释**：交叉熵直接衡量概率分布的差异，更符合分类任务的数学本质。MSE 衡量的是数值距离，对分类任务来说不是最优的度量

4. **实际效果**：在大量实验验证中，交叉熵在分类任务上几乎总是优于 MSE

### 1.6 损失函数选择指南

| 任务类型 | 推荐损失函数 | 输出层激活函数 | 原因 |
|---------|-------------|---------------|------|
| 回归 | MSE | 无（线性输出） | 惩罚较大误差，适合连续值预测 |
| 回归（含异常值） | MAE | 无 | 对异常值更鲁棒 |
| 二分类 | 二元交叉熵 | Sigmoid | 概率解释，收敛快 |
| 多分类（标签互斥） | 多元交叉熵 | Softmax | 输出概率分布，标签互斥 |
| 多标签分类 | 二元交叉熵 | Sigmoid | 每个标签独立判断 |

## 二、优化器（Optimizer）

优化器（Optimizer）是神经网络训练中负责更新模型参数的算法。它根据损失函数计算出的梯度，决定参数如何调整以使损失最小化。

### 2.1 梯度下降（Gradient Descent）

梯度下降是最基本的优化算法，核心思想是沿着**损失函数下降最快的方向**（即负梯度方向）更新参数。

**基本公式**：
```
θ = θ - η · ∇L(θ)
```

其中 `θ` 代表所有参数（权重和偏置），`η` 是学习率，`∇L(θ)` 是损失函数对参数的梯度。

**三种梯度下降变体**：

| 变体 | 每次更新使用的样本 | 优点 | 缺点 |
|------|------------------|------|------|
| **批量梯度下降（BGD）** | 全部训练数据 | 梯度准确，收敛稳定 | 速度慢，内存消耗大 |
| **随机梯度下降（SGD）** | 1 个样本 | 速度快，可能跳出局部最优 | 梯度噪声大，收敛不稳定 |
| **小批量梯度下降（Mini-Batch GD）** | 一小批样本（通常 32-512） | 平衡速度和稳定性，最常用 | 需选择合适批次大小 |

**Mini-Batch 梯度下降**是现代深度学习训练的标准选择，它在计算效率和梯度稳定性之间取得了最佳平衡。

### 2.2 动量（Momentum）

动量方法在 SGD 的基础上引入**速度**概念，模拟物理中的惯性效应。参数更新不再只依赖当前梯度，而是累积历史梯度方向。

**公式**：
```
v = βv + η∇L(θ)
θ = θ - v
```

其中 `v` 是速度（动量），`β` 是动量系数（通常取 0.9），`η` 是学习率。

**效果**：
- 在梯度方向一致时加速前进（如进入平坦区域或沿正确方向时）
- 在梯度方向变化时减少震荡（如在峡谷地形中左右摆动时）
- 帮助参数更快地穿过局部最优区域，找到更好的全局最优解

**直观理解**：想象一个球在损失函数构成的地形上滚动。动量使球不仅受当前坡度影响，还保留了之前的运动惯性，从而能更好地穿越平坦区域和跳出局部凹陷。

### 2.3 AdaGrad（Adaptive Gradient）

AdaGrad 是一种**自适应学习率**优化算法。它为每个参数单独维护一个学习率，对于频繁更新的参数降低学习率，对于稀疏更新的参数提高学习率。

**核心机制**：
- 累积每个参数的历史梯度平方和
- 用累积值的平方根来缩放学习率

**公式**：
```
r = r + ∇L(θ) ⊙ ∇L(θ)       # 累积梯度平方
θ = θ - (η / (√r + ε)) · ∇L(θ)
```

其中 `r` 是累积梯度平方，`⊙` 表示逐元素相乘，`ε` 是一个很小的常数（如 10⁻⁸）用于防止除零。

**适用场景**：
- 处理稀疏数据（如自然语言处理中的词嵌入）
- 适合需要不同参数有不同学习率的任务

**缺点**：
- 累积梯度平方会单调递增，导致学习率持续衰减，最终可能变得极小，训练过早停止

### 2.4 RMSProp（Root Mean Square Propagation）

RMSProp 是对 AdaGrad 的改进，它引入**指数移动平均**来替代 AdaGrad 的累积梯度平方，防止学习率过度衰减。

**公式**：
```
r = ρr + (1-ρ)∇L(θ) ⊙ ∇L(θ)
θ = θ - (η / (√r + ε)) · ∇L(θ)
```

其中 `ρ` 是衰减系数（通常取 0.9），表示历史累积值的保留比例。

**效果**：
- 既保持了 AdaGrad 的自适应特性
- 又避免了学习率过度衰减的问题
- 在非凸优化问题上表现良好，适合训练神经网络

### 2.5 Adam（Adaptive Moment Estimation）

Adam 是目前深度学习中使用最广泛的优化器之一，它同时结合了 **Momentum** 和 **RMSProp** 的优点：
- 一阶矩估计（类似于 Momentum）：累积梯度的一阶矩（均值），控制更新方向
- 二阶矩估计（类似于 RMSProp）：累积梯度的二阶矩（平方的均值），控制学习率大小

**公式**：
```
m = β₁m + (1-β₁)∇L(θ)        # 一阶矩估计（动量）
v = β₂v + (1-β₂)∇L(θ)⊙∇L(θ) # 二阶矩估计（梯度平方的累积）

m̂ = m / (1-β₁ᵗ)                # 偏差修正
v̂ = v / (1-β₂ᵗ)                # 偏差修正

θ = θ - (η / (√v̂ + ε)) · m̂
```

其中：
- `m`：一阶矩（梯度均值），类似于动量
- `v`：二阶矩（梯度平方均值），类似于 RMSProp 的累积值
- `β₁` 通常取 0.9，控制动量衰减
- `β₂` 通常取 0.999，控制梯度平方累积衰减
- `t` 是当前迭代次数，用于偏差修正（在训练初期更准确）

**优点**：
- 自适应学习率，每个参数有自己的学习率调整
- 动量加速收敛
- 对超参数选择不敏感，默认参数在大多数问题上表现良好
- 适合大规模数据和参数

**缺点**：
- 在某些任务上泛化能力略差于 SGD（可能在测试集上表现不如 SGD 好）
- 后期可能收敛到次优解

### 2.6 优化器对比与选择

| 优化器 | 核心思想 | 优点 | 缺点 | 适用场景 |
|-------|---------|------|------|---------|
| **SGD** | 基本梯度下降 | 简单，泛化能力强 | 收敛慢，需调学习率 | 大型数据集，需要最佳泛化时 |
| **SGD + Momentum** | 梯度 + 动量 | 加速收敛，减少震荡 | 需调两个超参数 | 通用，推荐作为基准 |
| **AdaGrad** | 自适应学习率 | 适合稀疏数据 | 学习率过早衰减 | 稀疏数据（如 NLP） |
| **RMSProp** | 自适应 + 衰减修正 | 避免学习率过度衰减 | 不如 Adam 稳定 | 非凸优化，RNN 训练 |
| **Adam** | 动量 + 自适应 | 收敛快，超参数不敏感 | 泛化可能略差 | 快速实验，大规模数据 |

### 2.7 学习率调度（Learning Rate Scheduling）

即使选择了合适的优化器，固定学习率通常不是最优策略。学习率调度策略在训练过程中动态调整学习率：

**常用策略**：
- **Step Decay**：每隔固定轮数将学习率乘以一个因子（如每 10 轮乘以 0.1）
- **Exponential Decay**：学习率按指数函数衰减 `η = η₀ · e^(-kt)`
- **Cosine Annealing**：学习率按余弦曲线周期性变化，有助于跳出局部最优
- **Warm-up**：训练初期使用很小的学习率，然后逐渐增大，防止早期梯度爆炸
- **ReduceLROnPlateau**：当验证集损失不再下降时自动降低学习率

**选择建议**：
- Adam 通常不需要复杂的学习率调度（因为它本身自适应）
- SGD 通常配合学习率调度能获得更好的效果
- 大型模型（如 Transformer）通常需要 Warm-up 策略

### 2.8 优化器选择的实践建议

1. **快速实验和原型开发**：使用 Adam，默认参数 (β₁=0.9, β₂=0.999, lr=0.001)，无需太多调参即可得到不错的效果

2. **追求最佳性能**：先用 Adam 快速找到大致参数范围，再切换到 SGD + Momentum 进行精细调优，配合学习率调度，往往能获得更好的泛化性能

3. **稀疏数据（如 NLP）**：Adam 或 AdaGrad 的变体表现更好

4. **RNN / LSTM 训练**：RMSProp 或 Adam 通常更稳定，因为 RNN 的梯度容易出现剧烈波动

5. **避免 Adam 泛化差的问题**：使用 AdamW（Adam 的变体，对权重衰减进行正确解耦），或在使用 Adam 时配合学习率衰减和早停策略

## 三、损失函数与优化器的关系

损失函数和优化器是神经网络训练中**不可分割**的两个组件：

- **损失函数**定义了训练目标："我们希望模型学到什么"（预测值与真实值之间的差距）
- **优化器**定义了实现路径："我们如何达到这个目标"（如何利用梯度更新参数）

两者的选择需要匹配：
- 分类任务需要交叉熵损失 + 适合分类优化的优化器（如 Adam、SGD）
- 回归任务需要 MSE/MAE 损失 + 适合连续值优化的优化器
- 损失函数的选择影响梯度的性质，进而影响优化器的效率

例如，当使用交叉熵损失配合 Sigmoid 或 Softmax 时，梯度计算中恰好会抵消激活函数在极端值处的导数衰减，避免了梯度消失问题。这就是为什么分类任务中 "交叉熵 + Sigmoid/Softmax" 的组合比 "MSE + Sigmoid/Softmax" 收敛更快的原因。

## 四、总结

| 组件 | 作用 | 关键选择 |
|------|------|---------|
| 损失函数 | 衡量预测与真实的差距 | 分类用交叉熵，回归用 MSE/MAE |
| 优化器 | 利用梯度更新参数 | 快速实验用 Adam，最佳性能用 SGD+Momentum |
| 学习率 | 控制参数更新步长 | 需配合学习率调度动态调整 |

理解损失函数和优化器的原理与选择策略，是构建高性能深度学习模型的基础。在实际应用中，建议先使用 Adam 进行快速验证，再考虑切换到 SGD 配合学习率调度来追求最佳性能。
