## 一、神经网络的基本概念

### 1.1 什么是神经网络

神经网络（Neural Network）是一种受人脑神经元连接方式启发的计算模型。它由大量简单的计算单元（称为神经元）相互连接组成，通过调整连接权重来学习数据中的模式，从而实现分类、回归、预测等任务。

在深度学习中，当我们说"神经网络"时，通常指**多层神经网络**（Multi-Layer Neural Network），即包含输入层、一个或多个隐藏层、输出层的网络结构。当隐藏层数量较多时，我们称之为**深度神经网络**（Deep Neural Network，DNN）。

### 1.2 神经元模型

神经元是神经网络的基本计算单元。一个典型的神经元接收多个输入信号，通过加权求和并加上偏置，再经过激活函数产生输出。

**数学表达**：

```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
a = f(z)
```

其中：
- `xᵢ`：第 i 个输入信号（来自前一层的输出或原始输入数据）
- `wᵢ`：第 i 个输入对应的权重，决定该输入的重要性
- `b`：偏置（bias），允许激活函数向左或向右平移，增加模型的灵活性
- `z`：加权求和的结果，也称为净输入（net input）
- `f(z)`：激活函数，引入非线性变换
- `a`：神经元的最终输出，将传递给下一层神经元

### 1.3 感知机（Perceptron）

感知机（Perceptron）是由 Frank Rosenblatt 于 1957 年提出的最简单的神经网络模型，只包含一个神经元，用于解决二分类问题。

感知机的输出规则：
```
如果 w·x + b > 0，输出 1（正类）
如果 w·x + b ≤ 0，输出 0（负类）
```

感知机只能解决**线性可分**的问题，对于 XOR 问题等非线性可分问题无能为力。这一局限曾导致神经网络研究在 1960-1980 年代陷入低谷，直到多层网络和反向传播算法的出现才重新兴起。

### 1.4 多层感知机（MLP）

多层感知机（Multi-Layer Perceptron，MLP）是对单层感知机的扩展，它在输入层和输出层之间增加了**一个或多个隐藏层**。隐藏层中的每个神经元都与前一层和后一层的所有神经元相连，这种连接方式称为**全连接**（Fully Connected）或**密集连接**（Dense Connection）。

**MLP 的典型结构**：
- **输入层**（Input Layer）：接收原始数据，神经元数量等于输入特征的维度
- **隐藏层**（Hidden Layer）：对输入数据进行非线性变换和特征提取，可以有一层或多层。隐藏层越多，网络越深，表达能力越强，但训练难度也越大
- **输出层**（Output Layer）：产生最终的预测结果。对于二分类，输出层通常有 1 个神经元；对于多分类，输出层神经元数量等于类别数

## 二、激活函数

激活函数（Activation Function）是神经网络的**非线性变换核心**。如果没有激活函数，无论网络有多少层，最终都只能表示线性映射，无法学习复杂的非线性关系。

### 2.1 为什么需要激活函数

假设没有激活函数，多层网络的计算过程可以写成：
```
Layer 1: z¹ = W¹x + b¹
Layer 2: z² = W²z¹ + b² = W²(W¹x + b¹) + b² = (W²W¹)x + (W²b¹ + b²)
```

可以看到，多层线性变换的复合仍然是线性变换。因此，必须引入非线性的激活函数，才能使网络具备学习复杂模式的能力。

### 2.2 常见激活函数

**Sigmoid 函数**：
```
σ(x) = 1 / (1 + e⁻ˣ)
```
- 输出范围：(0, 1)
- 优点：输出平滑、可导，适合表示概率
- 缺点：当输入值过大或过小时，梯度趋近于 0，导致**梯度消失**问题；输出不是零中心的，影响梯度下降效率

**Tanh 函数（双曲正切）**：
```
tanh(x) = (eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)
```
- 输出范围：(-1, 1)
- 优点：零中心输出，比 Sigmoid 收敛更快
- 缺点：仍然存在梯度消失问题

**ReLU 函数（Rectified Linear Unit，修正线性单元）**：
```
ReLU(x) = max(0, x)
```
- 当 x > 0 时，输出 x；当 x ≤ 0 时，输出 0
- 优点：计算简单，缓解梯度消失问题，收敛速度快，目前在隐藏层中应用最广泛
- 缺点：当输入为负时，梯度恒为 0，导致该神经元"死亡"（Dead ReLU），永远不再更新

**Leaky ReLU**：
```
Leaky ReLU(x) = max(αx, x)，其中 α 通常取 0.01
```
- 对 ReLU 的改进：在负半轴赋予一个很小的斜率，避免神经元完全死亡

**Softmax 函数**：
```
Softmax(zᵢ) = e^(zᵢ) / Σⱼ e^(zⱼ)
```
- 将输出转换为概率分布，所有输出值之和为 1
- 主要用于多分类任务的输出层
- 不适用于隐藏层，因为会与隐藏层中的非线性变换相互干扰

### 2.3 激活函数选择建议

| 网络层 | 推荐激活函数 | 原因 |
|-------|-------------|------|
| 隐藏层 | ReLU 或 Leaky ReLU | 计算简单，收敛快，缓解梯度消失 |
| 二分类输出层 | Sigmoid | 输出概率值 |
| 多分类输出层 | Softmax | 输出概率分布 |
| 回归输出层 | 无激活函数（线性输出） | 直接输出预测值 |

## 三、前向传播（Forward Propagation）

前向传播是指输入数据从输入层经过隐藏层，逐层计算到输出层的过程。每一层的计算都遵循"加权求和 + 激活函数"的模式。

### 3.1 计算过程

假设有一个三层网络（输入层、一个隐藏层、输出层）：

**隐藏层计算**：
```
Z¹ = W¹·X + b¹
A¹ = f(Z¹)      # f 是激活函数，如 ReLU
```

**输出层计算**：
```
Z² = W²·A¹ + b²
A² = g(Z²)      # g 是输出层激活函数，如 Softmax
```

其中 W¹、W² 是权重矩阵，b¹、b² 是偏置向量，X 是输入特征向量。

### 3.2 参数与超参数的区别

在神经网络中，需要区分两类参数：

- **参数（Parameters）**：通过训练过程自动学习得到的值，包括**权重（Weights）**和**偏置（Biases）**。这些参数决定了网络的映射能力
- **超参数（Hyperparameters）**：在训练前需要人工设置的值，包括学习率、网络层数、每层神经元数量、批次大小、正则化系数等。超参数的选择直接影响模型性能，通常需要通过实验（如交叉验证）来调优

## 四、反向传播算法（Backpropagation）

反向传播算法是训练神经网络的核心算法，由 Rumelhart、Hinton 和 Williams 于 1986 年提出。它通过**链式法则**高效计算损失函数对每个参数的梯度，从而指导参数更新。

### 4.1 核心思想

反向传播包含两个关键步骤：
1. **前向传播**：计算网络输出，得到预测值与真实值之间的误差（损失）
2. **反向传播**：从输出层开始，逐层向输入层传播误差，计算每一层参数对总损失的贡献（梯度），然后更新参数

### 4.2 链式法则（Chain Rule）

反向传播算法的数学基础是**链式法则**。在复合函数中，外层函数对内层函数的导数等于各层导数的乘积。

对于一个复合函数 `L = f(g(h(x)))`：
```
dL/dx = (dL/df) · (df/dg) · (dg/dh) · (dh/dx)
```

在神经网络中，损失函数 L 关于某一层权重 W 的梯度，可以通过从输出层到该层的所有偏导数相乘得到。

### 4.3 计算图（Computational Graph）

计算图是理解反向传播的直观工具。它将复杂的计算过程分解为一系列简单的操作节点，每个节点只执行一个基本运算（如加法、乘法、激活函数）。

**反向传播在计算图上的规则**：
- 从输出节点（损失）开始，向后遍历每个节点
- 在每个节点应用链式法则，将上游梯度乘以该节点的局部梯度
- 将梯度传递给所有输入节点
- 最终到达权重节点，得到损失函数对每个权重的梯度

### 4.4 参数更新过程

得到梯度后，使用**梯度下降**或其变体来更新参数：

```
W = W - η · (∂L/∂W)
b = b - η · (∂L/∂b)
```

其中：
- `η`（eta）是**学习率**，控制每次参数更新的步长。学习率过大可能导致震荡甚至发散；学习率过小导致收敛极慢
- `∂L/∂W` 是损失函数对权重 W 的梯度，指示了 W 应该朝哪个方向调整才能减小损失

### 4.5 梯度消失与梯度爆炸

在深层网络中，反向传播时梯度需要经过多层传递。由于链式法则中的梯度是连乘的，当激活函数的导数绝对值小于 1 时（如 Sigmoid 的导数最大值为 0.25），多层连乘后梯度会指数级衰减，导致浅层参数几乎无法更新，这种现象称为**梯度消失**（Vanishing Gradient）。

相反，如果权重初始化过大，导致梯度值大于 1，多层连乘后梯度会指数级增长，导致参数更新剧烈震荡，称为**梯度爆炸**（Exploding Gradient）。

**缓解方法**：
- 使用 ReLU 激活函数（导数在正半轴为 1，避免梯度衰减）
- 合理的权重初始化（如 Xavier/Glorot 初始化、He 初始化）
- 梯度裁剪（Gradient Clipping）
- 使用残差连接（Residual Connection，在深层网络中）
- 批归一化（Batch Normalization）

### 4.6 反向传播与梯度下降的关系

反向传播和梯度下降是两个不同的概念，但紧密配合：

- **反向传播**：计算梯度的高效算法。它回答了"损失函数对每个参数的导数是多少"这个问题
- **梯度下降**：利用计算出的梯度来更新参数的优化策略。它回答了"参数应该如何更新"这个问题

反向传播负责**求梯度**，梯度下降负责**用梯度更新参数**。两者缺一不可。

## 五、神经网络训练的完整流程

综合以上内容，一个神经网络的标准训练流程如下：

1. **初始化**：随机初始化所有权重和偏置（注意初始化策略，如 Xavier 初始化）
2. **前向传播**：将输入数据送入网络，逐层计算得到输出预测值
3. **计算损失**：使用损失函数（如交叉熵、MSE）计算预测值与真实值之间的误差
4. **反向传播**：从输出层开始，利用链式法则计算损失函数对每个参数的梯度
5. **参数更新**：使用梯度下降或其变体（如 Adam），根据梯度更新所有权重和偏置
6. **迭代**：重复步骤 2-5，直到损失函数收敛或达到预设的训练轮数

在每次迭代中，使用一小批数据（Mini-Batch）而非全部数据，可以平衡计算效率和梯度估计的稳定性，这是现代深度学习训练的标准做法。

## 六、总结

神经网络的核心组件包括：
- **神经元**：基本计算单元，执行加权求和与激活函数
- **网络结构**：输入层、隐藏层、输出层的层次化组织
- **激活函数**：引入非线性，使网络能学习复杂模式
- **前向传播**：数据从输入到输出的正向计算流程
- **反向传播**：从损失到参数的梯度反向传播，高效计算梯度
- **梯度下降**：利用梯度更新参数，使网络逐步学习

理解这些基础概念是掌握 CNN、RNN、Transformer 等更复杂网络的前提。反向传播算法尤其重要，它是目前几乎所有神经网络训练的基础。
